# 创中图表样式工作台

[打开网站](https://jdingaiy.github.io/zhihu-chart-studio/)

2026-10-20 更新：流量来源与地域分布支持左右布局，可调整间距及左右占比。PC 默认左右，手机默认上下。

已内置 2026-10-15 调试配置，包含五类图表及 PC / 移动端样式。首次打开会使用该配置；后续修改保存在各自浏览器中。

- `index.html`：可直接运行的完整网站，依赖、字体、地图与默认配置均已内置。
- `chart-config.json`：本次发布的调试配置快照，可在工作台中导入。
- `chart-studio-source.zip`：完整网站源码、配置与离线版。

图表使用 Recharts、ECharts；图标使用 Phosphor Icons。开源依赖版权信息保留在代码与源码包内。
